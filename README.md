# İva — Kişisel Yapay Zekâ Asistanı

İva, günlük soruları yanıtlamak ve sesli sohbet etmek amacıyla geliştirilen kişisel yapay zekâ asistanı projesidir.

## Proje Yapısı

- Iva.Api: API uç noktaları.
- Iva.Application: Uygulama iş akışları ve servis arayüzleri.
- Iva.Domain: Temel modeller ve iş kuralları.
- Iva.Infrastructure: Harici servis entegrasyonları.

## Hedeflenen Özellikler

- Yapay zekâ ile yazılı sohbet.
- Mikrofon üzerinden sesli iletişim.
- Yanıtların sesli okunması.
- Masaüstü uygulaması.
- Seslenme sözcüğüyle etkinleştirme.

## Durum

Proje geliştirme aşamasındadır. Hedeflenen özellikler aşamalı olarak eklenecektir.
